Introduction In typical wireless communication systems, transmitters and receivers exchange waveforms according to agreed protocols. However, previous protocols for waveforms are not always feasible, and heterogeneous radios may need to communicate without predefined waveform protocols. In many applications, blind receivers must reconstruct and decode unknown waveforms in the absence of a known protocol. Civil applications include decoding unknown signals to enable dynamic frequency-division multiple access (DFA) between heterogeneous radios for message exchange. Military applications of blind decoding include intercepting enemy communications.
Decoding of blind received signals is a challenging problem. In addition to all channel impairments faced by protocol-based communication, blind receivers lack any knowledge of the signal being transmitted. Without agreed preamble codes for synchronization and channel estimation and unaware of the modulation type, blind receivers can only access IQ sample sequences representing unknown symbols. The receiver needs to calculate the symbol rate, modulation type, channel impulse response for equalization, and compensate for carrier and timing synchronization errors to recover the transmitted symbols. Furthermore, the length of the blind received signal is not pre-determined.
While it is easy to generate signals with different parameters and channel distortions, developing blind signal processing algorithms that jointly estimate all these parameters is more challenging. Many existing works have utilized blind signal processing to solve blind decoding and modulation classification [1]-[3]. However, these works address the estimation problem separately, so they do not benefit from joint estimation, and many of their assumptions are unrealistic for blind receivers, such as assuming synchronization.
In the context of availability of training data, some estimation issues in blind decoding are addressed using deep learning individually; a neural network for estimating center frequency and timing offsets under non-blind QPSK signal conditions is proposed [4]. For modulation classification, deep neural networks demonstrate superiority over manually designed features in [5]. However, the use of blind decoding as a set of independent deep learning estimates has its drawbacks. It prevents the networks from sharing common features, thereby preventing them from performing joint estimation through learning dependencies between parameters present in the signal. It also rejects each network benefiting from the output of other networks, which can partially restore the signal and reduce distortion. To avoid these limitations, another option is to adopt end-to-end deep learning solutions that treat the signal as input and output symbols.
The use of black-box end-to-end neural networks for blind decoding also has its drawbacks. Unlike modulation classification or estimation, blind decoding requires application across the entire length of the signal, thus necessitating effective scalability. Compared to digital signal processing (DSP), deep learning may have higher computational complexity and lack interpretability [6]. To effectively scale, estimating unknown parameters and relying on DSP for compensation can be more computationally efficient than relying on end-to-end black-box neural networks. Moreover, interpretable outputs can easily be integrated with existing DSP technologies. The disadvantages of standalone estimation and end-to-end solutions prompt the adoption of model-based deep learning solutions [7], integrating signal processing and deep learning into a design that combines their advantages.
In many existing works addressing similar problems, another common limitation of neural networks is the fixed input size. For example, in [5], it was shown that using longer signals in networks can lead to improved modulation classification accuracy. However, the suggested network could only handle fixed-length signals and required redesign and retraining for changing input lengths. Blind receivers do not have control over the length of received signals, and training separate networks for each possible signal length is impractical. To use fixed-length networks on variable-sized inputs, one approach is to train them on short messages and divide longer signals into chunks, using the averages proposed in [8]. Another method that offers more flexibility is to design neural networks that process variable-length signals, as suggested in [9], [10]. However, it is currently unclear which approach yields better performance.
A dual-path network (DPN) blind decoding and modulation classification algorithm has been proposed. To overcome the limitations of separate estimation and end-to-end networks, the DPN is designed with two paths: a signal path and a feature path. The signal path includes linear signal processing operations that compensate for frequency offsets, noise, and fading sequentially. The feature path consists of neural networks that process features extracted from both the input and compensated signals. These features are used to predict interpretable signal processing estimates and filter taps. With this architecture, the DPN benefits from the recovered signals and can harvest all levels of characteristics from the combiner. Once estimated, due to their signal processing interpretations, they can be integrated with existing signal processing techniques. By leveraging average pools and recurrent networks to make predictions, the DPN can handle variable-length inputs. Our contributions can be summarized as follows:

To this end, we compared DPN with alternative architectures that cannot access the recovery signals or feature combinations, and demonstrated that DPN outperforms any architecture by up to 5% in modulation classification.

Through reliance on average pools and recurrent neural networks, DPN can handle variable-length inputs, which provide better estimation than splitting inputs into short blocks and averaging.
Although this work considers blind symbol decoding, the dual-path concept can be extended to other problems in wireless communication that utilize deep learning. By using feature paths composed of neural networks and signal paths operated by DSPs, the output can be compatible with existing signal processing methods. Moreover, this design inherently allows for reuse of intermediate outputs and feature sharing, both of which have been proven to significantly improve accuracy.
